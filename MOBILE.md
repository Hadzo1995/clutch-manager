# Clutch Manager on phones

The phone apps wrap the same web build as the website, with [Capacitor](https://capacitorjs.com/).
Gameplay, saves and data are identical; only the shell differs. There are three ways to play on a phone:

| Way | For | Needs |
| --- | --- | --- |
| Website, installed | Anyone with the link | Nothing: open the site, then "Add to Home screen" / "Install app" |
| Android app (APK) | Testing on your own Android phone | This PC (Java 21 and the Android SDK are set up in `C:\Users\mscam\tools`) |
| iPhone app | Testing on your own iPhone | Your Mac with Xcode |

Saves are stored per app: the website, the Android app and the iPhone app each keep their own career.
Use Settings → Export save / Load save file to move a career between them.

## 1. The website as an app (Android and iPhone)

After a merge to `main`, GitHub Pages serves the new version. On the phone:

- **Android (Chrome):** open the site → menu ⋮ → *Install app* (or *Add to Home screen*).
- **iPhone (Safari):** open the site → Share → *Add to Home Screen*.

It opens full screen with its own icon and keeps working offline after the first visit
(`public/sw.js` caches the game and the player photos). Online features still need a connection.

## 2. Android test app (APK) on Windows

From the project folder, in Git Bash:

```bash
export JAVA_HOME='C:\Users\mscam\tools\jdk-21'
export ANDROID_HOME='C:\Users\mscam\tools\android-sdk'
export PATH="/c/Users/mscam/tools/node-v22.23.4-win-x64:/c/Users/mscam/tools/jdk-21/bin:$PATH"
npm run build          # web build into dist/
npx cap sync android   # copies dist/ into the Android project
cd android && ./gradlew assembleDebug
```

The APK is `android/app/build/outputs/apk/debug/app-debug.apk`.

To install it on your phone:

1. Copy the APK to the phone (USB, Google Drive, or email it to yourself).
2. Open it on the phone. Android asks to allow installs from that app (Files, Drive or Gmail): allow it once.
3. Install, then open *Clutch Manager*.

Or, with USB debugging switched on (Settings → About phone → tap *Build number* 7 times → Developer options → *USB debugging*):

```bash
/c/Users/mscam/tools/android-sdk/platform-tools/adb.exe install -r android/app/build/outputs/apk/debug/app-debug.apk
```

`android/local.properties` (not committed) points Gradle at the SDK:
`sdk.dir=C:/Users/mscam/tools/android-sdk`.

A Play Store release later needs a signed release build (`./gradlew bundleRelease` with an upload key) and the
one-time $25 Google Play developer account.

## 3. iPhone app on your Mac

One-time setup on the Mac:

1. Install **Xcode** from the App Store and open it once (it installs its components).
2. Install **Node.js 22** (from nodejs.org) and **Git**.
3. Clone the repository: `git clone https://github.com/Hadzo1995/clutch-manager.git && cd clutch-manager`.
4. `npm ci`

Each time you want a fresh build:

```bash
git pull
npm ci
npm run build
npx cap sync ios
npx cap open ios        # opens the project in Xcode
```

In Xcode:

1. Select the **App** target → *Signing & Capabilities* → tick *Automatically manage signing*, and choose your
   Apple ID as the **Team** (Xcode → Settings → Accounts → add your Apple ID if it is not there).
   A free Apple ID works for your own phone; the app then runs for 7 days before it needs a re-install.
2. If Xcode says the bundle identifier is taken, change `com.hadzo.clutchmanager` to something unique
   (for example `com.hadzo.clutchmanager.dev`).
3. Plug in the iPhone, unlock it, trust the Mac, and pick the iPhone at the top of Xcode.
4. Press ▶ Run. The first time, on the iPhone: Settings → General → VPN & Device Management → trust your
   developer profile. On iOS 16+ also switch on Settings → Privacy & Security → *Developer Mode*.

TestFlight and App Store releases need the paid Apple Developer Program ($99 a year).

## Where things live

- `capacitor.config.ts`: app id, name, splash and status bar settings.
- `android/`, `ios/`: the native projects (generated by Capacitor, committed; build output is ignored).
- `resources/`: icon and splash sources; regenerate with `node tools/app-icons.mjs` then
  `npx @capacitor/assets generate --iconBackgroundColor '#0a0e13' --splashBackgroundColor '#0a0e13' --android --ios`.
- `src/platform.ts`: native-only setup (status bar, splash) and the offline worker for the website.
- `src/ui/fonts.ts`: the fonts are bundled, so the app looks the same offline.
